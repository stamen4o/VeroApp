# VeroApp
Android Task Manager App — VERO Digital Solutions Technical Assignment

A clean, modern Android application built with MVVM + Repository architecture.
The app authenticates with the BauBuddy API, downloads tasks, stores them offline using Room,
and displays them in a searchable, filterable task list.
Includes QR code scanning, swipe-to-refresh, and automatic background refreshing through WorkManager.

Key features:

Secure login with token retrieval
Remote task API integration
Local caching (Room)
Full-model search (all fields)
QR code input → search
Periodic background sync (60 min)
Clean UI using Material Design 3
Modular MVVM architecture
Professional Git workflow
Stable → main, Development → dev, Feature branches per module


This repo is structured and documented to demonstrate clean code, architecture discipline, and professional Android practices.
Targets evaluation by VERO Digital Solutions.
